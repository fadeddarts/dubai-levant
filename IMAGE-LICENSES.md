# Image sources and licences

Every photograph on the DubaiLevant website is listed here. None of these pictures were taken at DubaiLevant, and none come from customer reviews, Google Images, or another restaurant’s website.

DubaiLevant has not supplied its own photography. These files are temporary culinary references. Replace them with restaurant-owned pictures when they are available, and update this file.

Commercial use is permitted by each licence below. Attribution is required. Adaptations of the images — the resized or cropped files in `public/images/` — stay under the same Creative Commons licence as the original. The website code is not part of that licence.

No Unsplash+ images, Adobe Stock files, or AI-generated images are used.
